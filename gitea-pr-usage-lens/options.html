Gitea PR Usage Lens

Gitea 주소

PR을 보는 Gitea 주소를 추가하세요. 하위 경로에 설치된 경우 경로까지 입력합니다. (예: https://git.example.com, https://example.com/gitea)

    추가 후 열려 있는 PR 페이지는 새로고침해야 적용됩니다.

    토큰 (필수)

    Gitea API는 브라우저 로그인 쿠키를 받지 않기 때문에, 저장소 코드를 읽으려면 주소마다 토큰이 꼭 필요합니다.

    1. Gitea → 오른쪽 위 프로필 → 설정 → 애플리케이션
    2. 새 토큰 생성: 권한은 repository: 읽기만 선택 (Gitea 버전이 오래되어 권한 선택이 없으면 그냥 생성)
    3. 생성된 토큰을 위 목록의 해당 주소 아래 칸에 붙여넣기 (입력하면 바로 저장됩니다)

    토큰은 이 브라우저의 확장 저장소에만 보관되고(동기화 안 됨), 해당 Gitea 주소로만 전송됩니다.
